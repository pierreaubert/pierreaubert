# Engineering from *first principles.*

I build tools to understand sound, create native interfaces, and simulate the physical world.

## Four open source projects

From audio DSP to physical simulation, these projects explore the space between mathematical models and practical tools.
Native interfaces make the results accessible. Open source makes the work available to inspect, question, and extend.
